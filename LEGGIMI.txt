DOSE VERDE 1.3 — RICERCA ASSISTITA

NOVITÀ
- ricerca prodotto per nome commerciale, anche parziale
- ricerca per numero di registrazione
- recupero anagrafica dal dataset Open Data del Ministero della Salute
- foto etichetta + OCR
- se l'OCR trova il numero di registrazione, avvia la ricerca ufficiale
- ricerca web assistita di etichette/schede tecniche
- analisi di pagine HTML e PDF per proporre possibili intervalli di dose/acqua
- i valori tecnici online NON vengono applicati in silenzio: devi premere sul valore candidato
- resta disponibile la compilazione manuale e il salvataggio come bozza

IMPORTANTE
Questa versione introduce funzioni server Vercel. Per aggiornare il progetto NON basta sostituire index.html.

NEL REPOSITORY:
1. sostituisci index.html
2. aggiungi la cartella api con:
   - search.js
   - find-technical.js
   - analyze.js
3. aggiungi package.json
4. sostituisci vercel.json con quello di questo pacchetto
5. Commit changes
6. attendi il nuovo deployment Vercel

NOTE
- Il calcolo e l'archivio restano locali nel browser.
- Ricerca ufficiale, OCR e ricerca tecnica richiedono Internet.
- L'OCR usa Tesseract.js caricato dal CDN.
- La ricerca ufficiale usa l'Open Data del Ministero della Salute e legge automaticamente il file JSON settimanale pubblicato.
- La ricerca tecnica è assistita/best-effort: controlla sempre che la fonte sia corretta e che i dati riguardino esattamente il prodotto/impiego selezionato.

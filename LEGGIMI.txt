DOSE VERDE 1.5.1 — PDF LOCALE / FALLBACK HTTP 403

PROBLEMA RISOLTO
Alcuni siti ufficiali (per esempio Bayer CropScience) permettono al normale browser di aprire un PDF,
ma bloccano le richieste automatiche provenienti da server cloud come Vercel con HTTP 403.
Non è un errore del PDF né dell'URL.

NUOVA FUNZIONE
Nella sezione "Scheda tecnica / etichetta online" trovi ora:
- URL + Analizza (come prima)
- Carica PDF + Analizza PDF caricato

Se il sito risponde 403:
1. apri il PDF in Safari;
2. salvalo in File;
3. torna a Dose Verde;
4. scegli il PDF;
5. premi "Analizza PDF caricato".

Il PDF viene letto direttamente nel browser dell'iPad/iPhone e non viene richiesto nuovamente al sito Bayer.
L'app prova poi a estrarre dosi, volume d'acqua, base di calcolo e scenari come nella normale analisi online.

Se il PDF è una scansione senza testo, usa invece la foto + OCR.
